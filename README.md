# 루미 도우미 (RummiAssist)

루미큐브 게임 화면을 캡처해 타일을 인식하고, 규칙에 맞게 손패를 가장 많이 낼 수 있는 배치(판 재배치 포함)를 게임 화면 위에 표시하는 Android 앱.

## 사용
1. APK 설치 → 앱에서 「접근성 서비스 켜기」 (막히면 앱 정보 → ⋮ → 제한된 설정 허용)
2. 게임 화면에서 떠 있는 「루미」 버튼 탭 → 분석
   - 실선 테두리: 손패에서 낼 타일(번호 = 세트), 점선: 판에서 옮길 타일
   - 패널의 「첫 등록 완료」를 끄면 손패만으로 30점 등록 조합을 찾음

## 구조
- `core/` 순수 Kotlin(JVM) — `Recognizer`(타일 인식, 판 세트 구분), `Solver`(규칙 DP), `Advisor`(기존 세트 유지·화면 매핑)
- `app/` 접근성 서비스 하나로 캡처(`takeScreenshot`)와 오버레이 표시

## 테스트
```
JAVA_HOME=/opt/homebrew/opt/openjdk@17 ./gradlew :core:test
```
- 실제 캡처 4장 × 배율 0.7~1.4 정확 인식
- 합성 화면(판 타일 폭 30~115px, 손패 48~120px, 세트 붙음/떨어짐, 기기 배율) 무작위 검증 — 판 타일 폭 23px 이상에서 모두 통과
- 솔버: 무작위 국면 전수 탐색과 최적값 일치
